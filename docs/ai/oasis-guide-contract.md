# Oasis Guide contract

Oasis Guide is a deterministic approved-content retrieval interface, not an open-ended chatbot.

It may answer only about the published demo programs, tour flow, illustrative meals/fees, and official Ottawa separation. Every result includes source title/reference, confidence language, an escalation path, and a refusal flag.

It must refuse or decline to infer availability, eligibility, admission, waitlist position, health/diagnosis information, child images, operational guarantees, or unapproved policy. It receives no tour-form data and makes no remote AI call.
