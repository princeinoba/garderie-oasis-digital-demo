# Garderie Oasis Digital Experience case study

## Problem

The original public journey had a `/blank` routing failure and relied on phone/email-only tour friction. Families lacked a clear mobile path from discovery to a transparent, privacy-minimized next step, and the official Ottawa registry boundary needed to be unmistakable.

## Clean-room response

Seven owner-supplied design boards established the authoritative warm, botanical, editorial direction. A clean-room Next.js rebuild created original components/assets and selectively adapted only technical foundations from the audited NurtureOps archive. Archive Git history, product identity, broad operations schema, environment values, and deployment evidence were excluded; the AI SDK archive remained reference-only.

## Experience

The public story moves from programs and daily rhythm through illustrative meals/fees to a responsive three-step tour preview. The 320px flow keeps one decision per section, labels every input, summarizes errors, reviews details before acknowledgement, and then states that nothing was saved or sent. Ottawa's official registry is linked and separated throughout.

## Trust architecture

Privacy minimization removes child identity, health, custody, photo, and finance fields. Same-origin, honeypot, rate-limit, schema, secure-cookie, no-store, CSP, forced-RLS, and append-only contracts form the security baseline. Oasis Guide uses approved local content, provenance and refusals; staff drafts remain proposals requiring human approval with no tool or delivery side effect.

## Accessibility and verification

Semantic landmarks, skip navigation, focus-visible states, reduced-motion and forced-colours support, labels, live regions, focused confirmation, keyboard navigation, responsive overflow checks, Axe, unit/integration/RLS/PWA/E2E suites, and an optimized production build comprise the release gate. Measured final results and deployment identifiers are added to release evidence after execution.

## Limitations and status

This is a synthetic, non-affiliated portfolio demonstration. It does not prove real availability, fees, menus, staff, licensing, policies, booking, admission, or waitlist status. Remote AI, Supabase persistence, messaging, analytics, and custom domains remain off. Privacy/legal copy needs professional review before real activation.
