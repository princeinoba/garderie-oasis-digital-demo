# Known limitations

- This is an independent portfolio demonstration, not a live Garderie Oasis or City of Ottawa service.
- Tour data is intentionally not persisted or delivered; confirmations and calendar files are previews.
- Director authentication is a shared synthetic cookie demonstration, not production identity or MFA.
- Rate limiting is in-memory per runtime instance, not distributed.
- Oasis Guide and proposal drafts are deterministic; no remote AI quality/cost/latency evaluation is claimed.
- Supabase schema and RLS are contract-tested but not applied to a live project in initial mode.
- Illustrative fees, menus, schedules, staff, availability, and program details are not operational facts.
- Privacy/legal wording requires professional review before real-world activation.
- Axe and keyboard checks cannot substitute for testing with people who use assistive technologies.
- No custom domain is configured or changed.
