# Operations

The initial demo has no database, queue, cron, email, SMS, analytics, remote AI, or real operational dependency. Monitor Vercel deployment/build/runtime status and `/api/health`; it reports synthetic mode with persistence disabled.

Incident priorities: disclosure of real data or secrets, unauthorized director access, cross-origin submissions, cache exposure of protected routes, misleading affiliation/availability claims, or incorrect official Ottawa links. Disable the deployment or roll back first, preserve evidence, rotate any affected credential, then document remediation.

Retention jobs are not active because public submissions are not persisted. Future persistence requires an owner-approved deletion schedule, verified access/correction/deletion workflow, and operational alerts.
